# Install RetroWin

Get RetroWin up and running on your Mac in minutes.

## Download RetroWin

1. Go to the [RetroWin Releases page](https://github.com/a1245582339/RetroWin-Release/releases)
2. Download the latest `.dmg` file
3. Open the DMG and drag RetroWin to Applications
4. On first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**

## System Requirements

- macOS 15.0 (Sequoia) or later
- Apple Silicon or Intel Mac
