# Install RetroWin

Get RetroWin up and running on your Mac in minutes. RetroWin is a native macOS app distributed as a DMG — no App Store account required.

## Download RetroWin

1. Go to the [RetroWin Releases page](https://github.com/a1245582339/RetroWin-Release/releases)
2. Download the latest `.dmg` file
3. Open the DMG and drag RetroWin to Applications
4. On first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**

## System Requirements

- macOS 15.0 (Sequoia) or later
- Apple Silicon or Intel Mac

## After Installation

Grant **Accessibility** permission in **System Settings → Privacy & Security → Accessibility** so RetroWin can track windows and show them on the taskbar.
