# 安装 RetroWin

几分钟即可在你的 Mac 上运行 RetroWin。

## 下载 RetroWin

1. 前往 [RetroWin Releases 页面](https://github.com/a1245582339/RetroWin-Release/releases)
2. 下载最新的 `.dmg` 文件
3. 打开 DMG，将 RetroWin 拖入「应用程序」文件夹
4. 首次启动时，前往 **系统设置 → 隐私与安全性**，点击 **仍要打开**

## 系统要求

- macOS 15.0（Sequoia）或更高版本
- 支持 Apple Silicon 和 Intel Mac
